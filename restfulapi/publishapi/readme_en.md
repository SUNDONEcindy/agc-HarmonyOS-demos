# Operate App Based on the Publishing API

## Overview

This sample code shows how to use code to call the Publishing API to query detailed information about HarmonyOS App and Atomic Service. 


## Configuration and Usage

1. Download the demo and replace the values of clientId, clientSecret, and appId in the **PublishApiDemo** with the actual values of the application. For details on how to obtain it, please refer to [here](https://developer.huawei.com/consumer/en/doc/app/agc-help-view-app-info-0000002282674569).
2. Run the **PublishApiDemo** project.


## Project Directory

```
├──publishapi_demo/src/test       // Code area       
│  ├──GetAppInfo.java             // Query App information
│  ├──GetToken.java               // Get the Token
│  └──PublishApiDemo.java         // Main program
```
